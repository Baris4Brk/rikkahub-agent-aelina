# P3 operational temporal facts — demand gate cancelled

Date: 2026-08-13
Decision identity: `22b6fd9725803087842aadc5d9df8c7179889a5494220d1dfde4074b98c432f7`

The conditional P3 phase is cancelled, not failed and not partially enabled.

No versioned evaluation corpus demonstrates a high-frequency set of non-personal operational
questions that cannot be handled by Conversation authority, reviewed Dreaming projections,
reviewed Policy, or live tool lookup. Consequently neither a fact authority/lifecycle nor a
benefit greater than extraction cost and wrong-structure/privacy risk has been established.

Therefore:

- `temporalOperational` remains hard-disabled in production settings projection;
- no bitemporal Learning schema, extractor, or retrieval path is created;
- personal identity, preference, relationship, health, or financial facts remain forbidden P3
  domains;
- P0–P2 and P5 are not blocked by this cancellation;
- a future proposal must supply a versioned non-personal corpus and pass
  `TemporalOperationalDemandGate` before any store-design migration is considered.
